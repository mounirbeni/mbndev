# MBN DEV brand kit for social posts

- `mbndev-icon-transparent.png` — official monogram, real alpha channel (128×128). Use at ≤176px in a 1080×1350 post.
  Do not upscale beyond that. Never use `brand-logo.webp` (it has a black box).
- Wordmark is live text, never an image: Inter 900, letter-spacing -0.015em.
  `MBN` = #f4f0ff (text-shadow 0 0 8px rgba(196,181,253,.18)) · `DEV` = #a855f7, margin-left 0.33em (text-shadow 0 0 9px rgba(168,85,247,.27)).
- Lockup in the footer: icon 44px + wordmark 24px, gap 12px, left margin 96px, y = 1206.
- Full spec: BRAND_GUIDE.md. Templates: video/brand-ad (carousel.html, creative.html, series.html) — on branch `claude/mbn-dev-brand-guide-uw45fi`, not on master.
